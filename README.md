# FdF — каркасная 3D-модель карты высот

![скриншот](docs/screenshot.png)

## Описание
Программа читает карту высот из файла `.fdf` и рисует её каркасную (wireframe) модель
в изометрической проекции. Карта автоматически масштабируется и центрируется
по размеру окна. По мотивам проекта FdF школы 42.

## Установка и запуск
Нужен Python 3.12+.

    python -m venv .venv
    .venv\Scripts\Activate.ps1          # Windows; в Linux/macOS: source .venv/bin/activate
    pip install pygame-ce
    python main.py maps/10-2.fdf

Для тестов и проверок дополнительно: `pip install pytest mypy ruff`.

Коды возврата: `0` — успех, `1` — ошибка чтения или формата карты, `2` — неверные аргументы.

## Управление
| Клавиша | Действие |
|---|---|
| Esc | Выход |
| Закрытие окна | Выход |
| Изменение размера окна | Карта масштабируется под новый размер |

## Формат карты
Текстовый файл: строка — ряд точек (координата y), позиция значения в строке — x,
значение — высота z (целое, может быть отрицательным). Значения разделяются пробелами.

    0  0  0  0
    0  5  5  0
    0  5,0xFF0000  5  0
    0  0  0  0

- все строки содержат одинаковое число значений, пустые строки в конце игнорируются;
- к высоте через запятую можно добавить цвет `0xRRGGBB`; ведущие нули можно опускать
  (`0xff` — синий), регистр букв любой;
- при ошибке программа сообщает строку и колонку, например
  `строка 2, колонка 3: 'x' — не целое число`.

## Структура проекта
| Файл | Назначение |
|---|---|
| `main.py` | Точка входа: аргументы командной строки, сообщения об ошибках, коды возврата |
| `fdf/errors.py` | Исключения `FdfError` и `MapFormatError` |
| `fdf/model.py` | Модель данных: `Point`, `Map` (соседи, рёбра каркаса) |
| `fdf/parser.py` | Чтение и проверка файла карты |
| `fdf/projection.py` | Изометрическая проекция, `Camera.fit` — масштаб и центрирование |
| `fdf/app.py` | Окно на pygame-ce — единственный модуль, который импортирует графику |
| `tests/` | Тесты парсера, модели, проекции и точки входа |
| `maps/` | Карты; в `maps/bad/` — карты с ошибками для тестов |
